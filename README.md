# night-market-marbles 夜市彈珠台

一個單檔 HTML 的夜市風格彈珠台小遊戲。按住拉桿蓄力、放開發射，彈珠穿過釘陣與紅色彈墊，落進得分杯或底部格子得分。

## 怎麼玩

- 用瀏覽器直接開啟 `index.html` 即可，不需安裝或建置。
- 按「開始」，每局 10 顆彈珠。
- 按住「拉桿」按鈕、按住遊戲畫面，或按住空白鍵蓄力；放開發射。
- 力道不夠時彈珠會滑回原位，可以再拉一次，不會少一顆。
- 遊戲結束後按空白鍵或 Enter 也能直接再玩一局。

## 有趣的地方

- **連擊加倍**：5 秒內連續得分會累積連擊，倍率最高 ×5，畫面左上會亮出目前的倍率。
- **金珠**：每顆彈珠約有 12% 機率是金珠，該顆得分 ×3；每局保底至少一顆，若前面都沒中，最後一顆會變成「壓軸金珠」。
- **中大獎**：敲進中央 500 杯，老闆再送 2 顆彈珠，並進入 8 秒「好運加倍」（得分 ×2），跑馬燈會加速閃爍。
- **聲光回饋**：進球有煙火粒子、畫面震動、連擊音階與結束排名（從「夜市新手」到「夜市彈珠之神」）。

## 計分

| 位置 | 分數 |
|---|---|
| 中央杯 | 500（另送 2 顆彈珠＋好運加倍） |
| 兩側杯 | 200 |
| 底部 7 格（左到右） | 50 / 10 / 20 / 100 / 20 / 10 / 50 |

實際得分 = 格子分數 × 連擊倍率 × 好運倍率 × 金珠倍率。最高分只存在你自己瀏覽器的 localStorage。
